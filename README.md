##  Описание проекта
Данная лабораторная работа является продолжением предыдущих этапов разработки персонального веб-сайта. В проект интегрирована программная логика на языке **JavaScript**, выполняющая роль аналитической панели для предпринимателя/стартапера. 

Скрипт производит динамический расчет ключевых финансовых показателей на основе массива дневной выручки, обрабатывает ввод имени пользователя и выводит результаты напрямую в элементы интерфейса страницы (DOM).

##  Выполненные задачи и функционал

1. **Интерактивное приветствие (`prompt` / DOM):**
   - Реализован запрос имени пользователя при загрузке страницы.
   - Персонализированное приветствие подставляется в заголовок страницы через манипуляцию с DOM-деревом.

2. **Работа с данными и массивами:**
   - Создан массив `revenues`, содержащий показатели дневной выручки стартапа.

3. **Функции и циклы:**
   - **`getSum(arr)`**: функция для расчета суммарной выручки за весь период (использует цикл `for`).
   - **`getMax(arr)`**: функция для поиска максимальной выручки за один день.
   - **Анализ низких показателей:** реализован подсчет количества и доли дней с низкой выручкой ($\le 3000\text{ ₽}$).

4. **Интеграция с HTML/CSS:**
   - В сессию метрик (`#metrics`) добавлен новый аналитический блок.
   - Все расчетные данные динамически выводятся в теги `<span>` с соответствующими `id`.

5. **Условия и отладка (`if / else`, `console`):**
   - Добавлена проверка среднего значения выручки с выводом предупреждений и аналитики в консоль разработчика (`console.log`, `console.warn`).
